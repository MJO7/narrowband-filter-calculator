How the calculation works

The model treats the entrance pupil as an annulus. For each pupil radius r, the ray angle is atan(r / focalLength). The interference filter center shifts blue according to λ′ = λ₀ √(1 − sin²θ / n_eff²). Transmission at the selected emission line is then weighted by each infinitesimal annular area 2πr dr and numerically integrated with Simpson's rule.

With no measured curve loaded, the passband is a flat-top profile with Gaussian shoulders. With a measured curve loaded, the uploaded curve is shifted by the same angle-of-incidence model and linearly interpolated.
